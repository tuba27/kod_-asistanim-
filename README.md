# Projenin Adı: Kod-Asistan v0.1

## Projenin Amacı
Kullanıcılara günlük işlerinde (hesaplama, selamlama vb.) yardımcı olacak bir dijital asistan tasarlamak.

## Projenin Hedefleri
* v1.0 Akıllı Menü özelliğini eklemek
* v2.0 Veri Saklama ve geçmiş kaydetme özelliğini eklemek

## Projenin Kapsamı
Asistan, kullanıcının girdiği komutları veya değerleri kontrol eder. Eğer girilen değer belirlenen kritik eşiğin altındaysa uyarı verir, üstündeyse normal işlem adımlarına devam eder.
